# 流星花园 · Meteor Garden

一个使用 Three.js 制作的星空幻想花园。六个区域连成可探索的世界，支持第一／第三人称、步行／飞行、区域传送、天空变化和地标互动。

## 最快打开方式

**已有构建版：双击 `serve-built.cmd`，然后在浏览器打开 `http://127.0.0.1:4173/`。**

- 需要已安装 Node.js，建议 Node.js 22.12 或更新版本。
- 构建版使用 Node 自带的本地静态服务器，不需要安装 npm 依赖，不需要联网。
- 保持命令窗口运行，关闭窗口或按 `Ctrl+C` 即停止服务器。
- 不要直接双击 `index.html`：浏览器的模块加载需要通过本地 HTTP 地址运行。
- 推荐使用桌面 Chrome 或 Edge，并开启浏览器硬件加速。第一版为键盘鼠标设计，未包含手机虚拟摇杆。

## 开发与修改

双击 `start-garden.cmd` 可启动开发版，首次缺少依赖时会联网安装。也可以在项目目录执行：

```powershell
npm ci --registry=https://registry.npmjs.org
npm run dev
```

开发地址通常为 `http://127.0.0.1:5173/`，具体以终端显示为准。

```powershell
npm test       # 运行地形、碰撞及实际角色控制测试
npm run build  # 更新 dist 构建版
```

## 如何探索

| 操作 | 功能 |
| --- | --- |
| W / A / S / D | 前后左右移动 |
| 鼠标拖动 | 环顾四周 |
| 点击场景 | 锁定鼠标，自由观察；浏览器不允许时可继续使用拖动 |
| Shift | 加速移动 |
| Space | 步行跳跃；飞行上升 |
| Ctrl | 飞行下降 |
| V | 切换第一／第三人称 |
| F | 开启飞行／返回步行 |
| E | 与附近地标互动 |
| R | 返回中央花庭入口 |
| H | 隐藏／恢复界面 |
| Esc | 释放鼠标并打开操作指南；在对话框中关闭对话框 |
| 鼠标滚轮 | 调整第三人称跟随距离 |

视角与移动方式可以自由组合。点击右下角星图中的数字，可以传送到对应区域。点击底部“全景俯瞰”可自动环绕观看，再次点击或移动返回旅人视角。

## 六个区域

1. **星愿花庭**：白石金边柱廊、星核喷泉、花圃、玫瑰拱门、长椅与灯具；靠近星核许愿，或者点击“许愿流星”触发流星雨。
2. **绯樱月宫**：双层开放亭阁、外部台阶、月亮装置、樱花树和拱桥；靠近月宫前庭唤醒樱雨。
3. **翡翠星湖**：带金属肋架的透明玻璃温室、水上音乐亭、栈道、睡莲、鱼群及波纹；音乐亭附近可触发环形光波。
4. **紫晶观星台**：层叠台地、机械星轨仪、望远镜、水晶簇；沿台阶进入互动范围后展开天空星图。
5. **琥珀风铃谷**：风车花坊、温棚、花车、木桶、水车、旗串与金色花田；风铃架附近可触发沿花谷流动的光点。
6. **云端流星岛**：三座浮岛、星门、柱廊、浮石、藤蔓与瀑布；可直接飞抵、通过小地图传送，或在地面传送阵按 E 前往。

## 场景设置

- **低画质**：关闭泛光和实时阴影，降低渲染分辨率与部分粒子数量；保留全部区域、建筑、花草和交互。
- **中画质**：默认选项，提供阴影、泛光、通透材质与全部动态。
- **高画质**：提高阴影贴图及允许的像素比。
- 天空在黄昏、星夜和黎明之间循环，正常刷新下约 12 分钟一轮。拖动时间滑块会暂停自动时间。
- “减少动态”降低装饰动画速度并停止生成新流星；已存在的流星会自然结束。
- 飞行切回步行时会落向脚下有效表面；若下方是没有落点的水域，会返回最近安全位置。

## 文件说明

| 路径 | 内容 |
| --- | --- |
| `index.html`、`src/` | HTML 入口、场景、建模工厂、角色控制、材质、动态和界面源码 |
| `dist/` | 可直接用静态服务器运行的构建产物，含打包后的 Three.js，无外部 CDN 依赖 |
| `scripts/serve.mjs` | 无第三方依赖的本地服务器，只监听 127.0.0.1 |
| `tests/` | 基于真实世界碰撞数据与角色控制器的自动化检查 |
| `docs/concept.png` | imagegen 生成的美术概念图，作为设计参考 |
| `docs/concept-prompt.md` | 概念图生成提示词和工具记录 |
| `docs/screenshots/` | 真实浏览器运行截图 |
| `docs/verification.md` | 测试结果、性能采样及实现边界 |

模型、植物与表面纹理由代码生成，随机布局使用固定种子。概念图不参与 3D 渲染；实际场景以运行截图和浏览器体验为准。水面使用环境色、金属高光及程序波纹近似表现反射，没有昂贵的屏幕空间反射。
