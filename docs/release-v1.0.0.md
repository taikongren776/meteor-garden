# 流星花园 v1.0.0 · 星空幻想花园

首个可探索版本：使用 Three.js 构建的星空幻想花园，包含六个主题区域、动态环境与自由漫游。

## 本次内容

- 六大区域：星愿花庭、绯樱月宫、翡翠星湖、紫晶观星台、琥珀风铃谷、云端流星岛。
- 第一／第三人称与步行／飞行自由组合，支持跳跃、加速、区域传送和全景俯瞰。
- 流星雨、樱花飘落、喷泉、鱼群、水面波纹、风车、水车、机械星轨仪及浮岛动画。
- 六处地标互动、黄昏／星夜／黎明循环、时间调节、三档画质及减少动态选项。
- 随包提供完整源码、构建产物、概念图、真实运行截图、中文说明及自动化测试。

## 下载与运行

1. 下载本页附件 `Meteor-Garden.zip` 并解压。
2. 安装 Node.js 22.12 或更新版本。
3. Windows 双击 `serve-built.cmd`，在浏览器打开 `http://127.0.0.1:4173/`。
4. 保持命令窗口运行。构建版无需安装 npm 依赖，运行时无需联网。

推荐桌面 Chrome 或 Edge，并开启硬件加速。请通过本地服务器访问，不要直接双击 HTML 文件。

开发版可执行 `npm ci` 和 `npm run dev`；修改后执行 `npm run build` 更新构建产物。

## 基本操作

WASD 移动，鼠标观察，Shift 加速，Space 跳跃／飞行上升，Ctrl 飞行下降。V 切换视角，F 切换飞行，E 互动，R 返回入口，H 隐藏界面，Esc 释放鼠标。点击右下角星图可传送。

## 当前范围

- 电脑键鼠优先，暂未提供手机虚拟摇杆。
- 重点为开放建筑与外部探索；未包含完整室内系统、多人联网、战斗或任务系统。
- 主要建筑使用简化碰撞，部分植物和装饰可穿过；水面使用近似反射。
- 互动以视觉反馈呈现，暂无音效；概念图作为美术参考，实际效果请查看运行截图。
